# 🏥 Healthcare Statistics & Probability

A small practical project to learn **Statistics and Probability** using a real-world healthcare dataset with Python.

## 🎯 Objective

The goal of this project is to understand basic statistical concepts by analyzing healthcare data and finding meaningful patterns.

## 📚 Topics Covered

- Data loading and understanding
- Data cleaning
- Descriptive statistics
- Mean, Median, and Mode
- Range, Variance, and Standard Deviation
- Quartiles and Percentiles
- Data Distribution
- BMI analysis
- Correlation
- Basic Probability
- Conditional Probability
- Normal Distribution
- Z-Score
- Sampling Concepts
- Hypothesis Testing
- T-Test & P-Value
- Statistical Interpretation

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook
